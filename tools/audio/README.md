# Музыка и звуки

Все звуки игры сгенерированы кодом из этой папки, сторонних записей нет, поэтому с лицензиями проблем нет
(банк инструментов FluidR3_GM под лицензией MIT). Готовые файлы лежат в `assets/audio/`, описание и громкость
каждого звука в `data/audio.json`, играет их автозагрузка `Audio` (`scripts/audio/audio_manager.gd`).

## Как пользоваться в игре

```gdscript
Audio.play_music("village")            # плавная смена музыки; "" останавливает
Audio.play_stinger("victory")          # короткая вставка: глушит или останавливает музыку
Audio.play_ambient("amb_forest")       # фоновая петля локации
Audio.play_sfx("melee_hit")            # звук; случайный вариант и разброс высоты из json
Audio.play_skill("fireball")           # звук применения навыка
Audio.play_skill_impact("fireball", crit)
Audio.play_status("frozen")            # статус наложен
Audio.play_surface("steam")            # появилась поверхность или облако
Audio.play_ui("ui_click")
Audio.set_volume("Music", 0.6)         # Master, Music, Ambient, SFX, UI; сохраняется в user://
```

Неизвестный id не роняет игру, а пишет одно предупреждение. Старые имена работают через `aliases` в json.

**Музыка** (петли): `theme_lado` (меню, «Тема Ладо» — народный вальс в ре дорийском), `funeral`

блокфлейта, капли калимбы), `combat` (народные барабаны, остинато струнных, фидл и валторны), `goblin_camp`
(фагот, пиццикато, туба, отрывистый «гоблинский» хор, деревянные барабаны), `boss_lado` (тема Ладо искажённая,

**Стингеры**: `omen` (колокол бьёт сам, гул земли, треск гроба, удар оркестра), `victory`, `defeat`,

подбор, монеты, дверь, сундук, переход, начало хода; щелчки интерфейса, страница, «печать» диалога.

## Как пересобрать

Нужны python3 с `numpy scipy mido`, `fluidsynth` с банком `FluidR3_GM.sf2` и `ffmpeg`
(в Ubuntu: `apt install fluidsynth fluid-soundfont-gm ffmpeg`, `pip install numpy scipy mido`).
Другой банк инструментов можно указать в переменной `RPG_SOUNDFONT`.

```
python3 tools/audio/build.py                 # всё (около минуты)
python3 tools/audio/build.py funeral bell    # только эти id
python3 tools/audio/build.py --music         # только музыка и стингеры
python3 tools/audio/build.py --sfx           # только звуки и фоновые петли
python3 tools/audio/build.py --check         # сверить data/audio.json с файлами
```

## Как устроено

- `musiclib.py` — нотация: мелодия пишется строкой (`"A4:2 G4 F4 | E4:1.5 F4:.5 D4:2"`), аккорды
  названиями (`"Dm C Bb A"`), дорожки — инструменты General MIDI. Песня пишется в MIDI, FluidSynth
  рендерит её с реверберацией, хвост реверберации переносится в начало, так что петля бесшовная.
- `songs.py` — партитуры всех треков и стингеров. Тема Ладо и её подголосок (`LADO`, `LADO_COUNTER`)
  в начале файла; чтобы поменять мелодию, правь строки и пересобирай.
- `sfx.py` — синтез звуков (шум, фильтры, резонаторы, форманты голоса, колокол) и фоновых петель.
- `dsp.py` — фильтры, реверберация, лимитер, выравнивание громкости, запись в OGG Vorbis.
- `build.py` — сборка и проверка. Громкость выравнивается по разделам (`TARGET`), тонкая подстройка —
  `volume_db` в `data/audio.json`.
