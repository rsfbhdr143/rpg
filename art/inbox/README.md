# Сюда кладутся картинки

Листы спрайтов, полосы анимаций, кадры отдельными файлами, GIF, атласы Aseprite/TexturePacker,
картинки из генераторов (на белом или однотонном фоне) и zip-архивы паков целиком. Подпапки можно любые.

Потом запусти `tools/art/import_art.bat` (Windows) или `python tools/art/import_art.py`.
Подробности — в разделе «Графика» в README.md в корне проекта.
